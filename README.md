# Magnum CPA Website — Setup Guide

## Your File Structure

Every folder has its own `README.md` that lists what's inside it.

```
single page magnum/
│
│  WEBSITE PAGES (published; must stay at the top: the file name is the web address)
├── index.html                    ← Home page  (magnumcpa.com/). Holds the MASTER menu, footer and search list
├── about.html                    ← /about: Max, our story, values, mission and reviews
├── services.html                 ← /services: the four service cards
├── tax-preparation-planning.html ┐
├── bookkeeping-payroll.html      │ the four service pages: GENERATED by tools/gen_services.py,
├── business-consulting.html      │ don't edit by hand
├── future-security.html          ┘
├── client-newsletter.html        ← /client-newsletter
├── tax-planning-newsletter.html  ← /tax-planning-newsletter
├── tax-videos.html               ← /tax-videos: the video gallery
├── financial-calculators.html    ← /financial-calculators (also the template for the service pages)
├── request-consultation.html     ← /request-consultation: the consultation form
├── contact.html                  ← /contact: phone, email, address, Google Business Profile
│
│  WEBSITE SETTINGS (must stay at the top)
├── CNAME                         ← connects the site to www.magnumcpa.com. NEVER delete or edit
├── sitemap.xml, robots.txt       ← tell Google which pages exist
├── _config.yml                   ← which files GitHub Pages keeps OFF the live site
├── _headers                      ← security settings for Cloudflare Pages (being set up)
├── .gitignore                    ← files that never go to GitHub
│
│  THINGS YOU DOUBLE-CLICK (not on the live site)
├── reviews.xlsx                  ← the Google reviews shown on the home page (Show = Yes/No)
├── update-reviews.bat            ← publishes reviews.xlsx to the website
├── sync.bat                      ← publishes all changes to GitHub
│
│  FOLDERS
├── images/    ← every picture the website uses (old unused ones in images/unused/)
├── docs/      ← notes and plans: CODE-MAP (where to change what), setup guides, history
├── tools/     ← small programs that build parts of the pages
├── versions/  ← save-version / restore-version: go back to an earlier website
├── worker/    ← the form backend on Cloudflare. NOT published by sync.bat
└── README.md  ← this file
```

### Keeping it organized
- **New web page:** at the top level (its file name becomes its address); add it to `sitemap.xml`, to the menu in
  `index.html` and to `PAGES` in `tools/sync_shared.py`, then run `python tools/sync_shared.py .`.
- **Menu, footer or search list:** change them in `index.html` only, then run `python tools/sync_shared.py .`;
  it copies them to every page.
- **New picture:** in `images/`; add a line to `images/README.md`. Pictures no longer used go to `images/unused/`.
- **New note or plan:** in `docs/`.
- **New helper program:** in `tools/`.
- Anything that must not be on the live website goes in the `exclude` list of `_config.yml`.
- Where to change a specific part of a page: see `docs/CODE-MAP.md`.

The client portal is **Canopy** — this website does not have its own login,
admin area, or client portal.

## Hosting

- **Domain:** `magnumcpa.com` is registered at **GoDaddy**, which also holds the DNS.
- **Website:** hosted free on **GitHub Pages** from the `main` branch of
  [github.com/glenn925/magnumcpa-website](https://github.com/glenn925/magnumcpa-website).
- **Email:** Google Workspace (MX records at GoDaddy point to Google). Never edit
  the MX or TXT records when changing website settings.
- **Lead form backend:** Cloudflare Worker in the company Cloudflare account
  (glenn@magnumcpa.com) at `https://magnum-cpa-lead-worker.glenn-c44.workers.dev` —
  see `docs/SETUP-CLOUDFLARE.md`.

### GitHub Pages settings
Repo → **Settings** → **Pages**: Source **Deploy from a branch**, Branch **main**,
folder **/ (root)**. Custom domain: `www.magnumcpa.com`, **Enforce HTTPS** on.

## Updating the Website

1. Save your changes
2. **Double-click `sync.bat`**
3. The live site updates within 1–2 minutes

Or use Terminal:
```
cd "C:\Users\Glenn\Documents\Claude\single page magnum"
git add -A && git commit -m "update" && git push
```

Changes inside `worker/` are **not** deployed by this — run `npx wrangler deploy`
from the `worker/` folder (see `docs/SETUP-CLOUDFLARE.md`).

---

## Security Rules

- The GitHub repo is public: **never** put passwords, API keys, or client data in any file.
  Worker secrets are set with `npx wrangler secret put <NAME>` and stay in Cloudflare.
- Keep 2-factor authentication on for GitHub, GoDaddy, Cloudflare, and Google Workspace.
