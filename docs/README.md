# docs: notes, guides and plans

Reading material for the website. Nothing in this folder is published on
magnumcpa.com (the whole folder is in the `exclude` list of `_config.yml`).

| File | What it is | When to open it |
|---|---|---|
| `CODE-MAP.md` | Where to find and change every part of the website (file + banner name), plus known issues | Before changing anything in the code |
| `MULTI-PAGE-PLAN.md` | Plan for giving every menu heading its own page (About, Contact, newsletters). Not built yet | When you decide to go ahead with it |
| `SETUP-CLOUDFLARE.md` | One-time setup of the consultation form backend (Cloudflare Worker, secrets, anti-spam) | When setting up or fixing the form backend |
| `RECENT-UPDATES.md` | Report of the June–July 2026 website changes (written August 2026) | History only |
| `lead-funnel-diagram.svg` | Diagram of how a consultation request flows: form, spam checks, backend, calendar | To explain the form to someone |

Put any new note, guide or plan in this folder and add a line to this table.
