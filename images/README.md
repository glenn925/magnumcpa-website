# images: every picture on the website

The pages load pictures from this folder by file name, so **renaming or moving a
picture breaks the page that uses it**. Search the `.html` files for the name first.
Most photos come in a few sizes: `.webp` (small, fast) with a `-700` mobile copy,
plus a `.jpg`/`.png` for old browsers.

This note is not published on the website (listed in `_config.yml`).
